01 / WORLD EXPLORER

Bu GitHub Pages sayfası başlangıç noktasıdır. Dünya klasörü ve ZIP seçimi, bilgisayarında çalışan uygulamada yapılır.

Önce START_WORLD_EXPLORER.bat dosyasını başlat. Save dosyan bu siteye yüklenmez.

Yerel kurulumu hazırla

WINDOWS · NODE.JS 24+ · JAVA

İlk kullanımda Node.js 24+, uyumlu Java ve hazırlanmış BlueMap 5.29 CLI kurulumu gerekir.

  1. 01
    ZIP’i indir ve bir klasöre çıkar.Gereksinimleri ve ayrıntılı kurulumu oku ↗
  2. 02
    Uygulama klasöründe kendi BlueMap yolunla çalıştır:
    node scripts/setup.mjs "C:/Path/To/BlueMap"
  3. 03
    START_WORLD_EXPLORER.bat dosyasını aç.

    Yerel uygulamada dünya klasörünü veya ZIP yedeğini seç. Daha hızlı başlamak için 2.000 blok çap ve 8–12 chunk deneyebilirsin.

Bu beta bir kaynak paketidir; tek tık kurulum paketi değildir. Render her kullanıcının kendi bilgisayarında hazırlanır.
